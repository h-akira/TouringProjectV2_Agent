# 詳細要件

[要件定義](01_requirements.md) の各ユーザーストーリーを、満たしたと判定できる具体的な条件に分けたもの。
画面の見た目・文言・配置は [画面モック](mock/index.html) に置き、ここには「何が満たされるべきか」だけを書く。

## 番号の付け方

- `US-<分類>-<連番>.<3桁の連番>`。例: `US-A-01.001` は US-A-01 の1つめの詳細要件。
- 連番は詰め直さない。使わなくなった番号は消さずに「（欠番）」とだけ書く。
- 「関連画面」は [画面一覧](02_screen_list.md) の ID。
