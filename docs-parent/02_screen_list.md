# 画面一覧

アプリが持つ画面と、それぞれの役割。画面どうしのつながりは [画面遷移図](03_screen_transition.md)、見た目と細かな振る舞いは [画面モック](mock/index.html)（画面 ID で引ける）。

## 1. 画面の分類

| 分類 | 意味 |
|---|---|
| 走行中 | 走行中にチラ見することがある。一瞬で読めることを最優先にする |
| 停車中 | 停車中か走行後に操作する。手袋のまま押せることを前提にする |

画面の下には「ホーム」「記録」「設定」の3つのタブを置き、各タブの最初の画面へいつでも移れる。
対話（SC-03）の間はタブを出さない。
文字で質問するときの入力のシートは、SC-02 の一部として扱う（独立した画面にしない）。

## 3. ダイアログ

| ID | ダイアログ | 出る場面 |
|---|---|---|
| DL-01 | 削除の確認 | 会話・走行・地点メモ・録音・接続キーを削除するとき |
| DL-02 | 新しい会話の確認 | 会話の文脈を区切るとき（区切ったことが分かるように一言添える） |
| DL-03 | ユーザー名の変更の確認 | ユーザー名を変えるとき（記録が引き継がれないこと、既にある名前なら切り替わることを示す） |

## 4. アプリの外

| ID | 対象 | 関わり |
|---|---|---|
| EX-01 | インカムのボタン | 押すと、どの画面にいても（アプリが閉じていても）SC-03 の録音中から始まる |
| EX-02 | 戻り先のアプリ（ナビ） | ハンズフリーで始めた応答のあと、SC-10 で選んだアプリへ戻る |
| EX-03 | 端末の通知 | 走行の記録中であることを示し、タップで SC-02 を開く |
