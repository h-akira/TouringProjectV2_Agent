# ユニットの定義

プロジェクトを構成するユニットと、それぞれの責務・担当するユーザーストーリー（[01_requirements.md](01_requirements.md)）。
ユニット間の約束は [07_units_contracts.md](07_units_contracts.md)、全体の方針は [05_technical_policies.md](05_technical_policies.md)、ユニットの中の作りは [08_design.md](08_design.md) と 08a〜08c。

## 1. ユニット一覧

| ユニット | 中身 | 公開 | IaC／配布 | リージョン |
|---|---|---|---|---|
| Android | Android アプリ（Kotlin・Jetpack Compose） | 公開 | 知人向けのテスト配信 | — |
| Backend | API・事実の確定・音声の処理・記録の保存 | 公開 | SAM | `ap-northeast-1` |
| Agent | 会話・回答の生成・Web 検索・周辺検索 | 公開 | AgentCore の CLI が生成する CDK | `us-east-1` |
| CICD | Agent・Backend のデプロイの仕組み | 非公開 | CloudFormation | — |

- ユニットごとにリポジトリを分け、親のリポジトリで束ねる。親はプロジェクト全体の要件・方針・契約を持つ。
- 学習の教材や調査の記録を別に置く場合も、それらはユニットではない（アプリの設計の対象外）。

## 2. Android

| 責務 |
|---|
| インカムのボタンで起動し、録音を始める。もう一度の押下か上限の時間で送る |
| インカムのマイクへの経路を張って録音する。録音の確認（試し録り・直近の録音の聞き直し）を持つ |
| 位置を監視し、走行のルートから進行方位を求める |
| 質問を送り、回答を受け取り、読み上げの音声を再生する。戻るタイミングの設定に従ってナビのアプリへ戻す |
| 通信できないときは、質問しようとした地点だけを記録する |
| 走行の記録（開始・一時停止・再開・終了・最長時間での自動終了）を行い、ルートを記録する |
| 地点メモを書く（文字・声）。声は文字起こしだけを Backend に頼む |
| 記録（走行・質問・地点メモ・メモ）を端末に持ち、Backend と同期する |
| 走行ごとの記録を、一覧と地図（国土地理院）で見せる |
| 会話の文脈の識別子を持ち、利用者の操作か設定した時間の経過で捨てる |
| ユーザー名・接続キー・各種の設定を持つ。接続キーは端末の安全な領域に保管する |
| アプリが背面にあっても、走行の記録・回答の待ち受け・読み上げを続ける |

| 担当する範囲 | 対応する US |
|---|---|
| 現在地・進行方位を質問に添える | A-01, A-02 |
| 会話の文脈の識別子の保持と破棄 | A-03, A-04 |
| 文字での質問 | A-08 |
| ハンズフリーの起動・終話・ナビへの復帰・状態の表示・失敗の通知・中止 | B-01〜B-07 |
| 回答の再生 | B-03, B-08 |
| 走行の記録・一時停止・自動終了 | C-01, C-02, C-07, C-08 |
| 記録の端末での保持と同期・通信できないときの後送 | C-03, C-04, C-05, C-09 |
| 確認用の音声の保持 | C-06, E-03 |
| 振り返り・記録の編集・地点メモ | D-01〜D-08 |
| 初回の準備・設定・ユーザー名 | E-01, E-02, E-04, E-05, E-06 |

## 3. Backend

| 責務 |
|---|
| API の入口（接続キーの確認・流量の制限・入力の検証） |
| 座標から住所を確定し、受けた進行方位・現在日時と合わせて AI への入力を組む |
| 質問の音声を文字にし、回答の読み上げ音声を作る |
| 地点メモの声を文字にする（AI には渡さない） |
| Agent を呼び、回答を非同期で返す |
| 会話の文脈の識別子を発行する |
| 記録をユーザー名ごとに保存し、Android との同期を受け持つ |
| 音声を一時的な保管にとどめ、処理が済んだら消す |

| 担当する範囲 | 対応する US |
|---|---|
| 住所・日時の確定と、方位を含む AI への入力 | A-01, A-02 |
| 会話の文脈の識別子の発行と Agent への受け渡し | A-03 |
| 回答から前置きを除く（読み上げに向けて整える） | A-07 |
| 文字起こし・音声合成 | B-03, D-08 |
| 記録の保存と同期 | C-03, C-04, C-05, C-09, E-05, E-06 |

## 4. Agent

| 責務 |
|---|
| 会話の文脈を保持する（設定した時間まで続けられる形で） |
| 回答を生成する（読み上げる前提の文体） |
| 必要なら Web 検索する |
| 周辺の施設を探し、距離・方角・左右を計算で求める |
| 使う AI モデルを設定値から読む |
| ツールを足す形で拡張できる構造を保つ |

| 担当する範囲 | 対応する US |
|---|---|
| 会話の文脈の保持 | A-03 |
| Web 検索 | A-05 |
| 周辺検索 | A-06 |
| 読み上げに向く回答 | A-07 |

## 5. CICD

| 責務 |
|---|
| Agent と Backend のデプロイ |
| Android の配布の設定手順（配布先のストア・CI の設定） |

直接担当する US は無い。AI モデルの設定値の変更は、デプロイを伴わない管理者の操作とする（[05_technical_policies.md](05_technical_policies.md) §5）。
